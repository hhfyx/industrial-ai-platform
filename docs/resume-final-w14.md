### 项目二｜缺陷图像生成服务：SD+LoRA · 异步队列（个人）

Python / FastAPI / diffusers / PEFT（LoRA）/ Docker（GPU 直通）/ SD1.5

给缺陷检测数据集做数据增广：产线大图 YOLO 裁剪出 **3,323 张、6 类**缺陷切片
（多源合并 +84%），SD1.5 + 每类别一个 LoRA 适配器（只训练 2.18M 低秩参数，
基座冻结），FastAPI 封装为同步 + 异步端点，单 worker 串行保护 GPU。

- **训练提速（126×，口径完整）**：初始实现每步在线 VAE 编码 → 改为一次性
  VAE 预计算全部 latent 缓存盘，单步 39s→0.31s（**126×**）、每 epoch
  19.5h→17min、显存 13GB→7GB（训练卡 11GB+ 档实测）
- **推理实测（消费级显卡口径）**：RTX 4050 6GB · FP16 · steps=25 下单张 512²
  **约 5.0s**（两轮 4.87–5.00s）、显存 2.81GB；**batch=4 吞吐反降约 15–19%**
  （反直觉结论，两轮复现）——6GB 卡上 batch 化不划算
- **异步化收益（架构，不是 GPU 加速）**：提交接口 P50 **4.2ms**（202 + task_id +
  轮询）vs 同步阻塞 ~5s；GPU 单 worker 串行 + 参数级幂等复用（重复请求
  0 GPU 占用）；状态机表驱动，非法迁移当场抛
- **部署**：GPU 镜像实测 12.8GB（其中 12.1GB 为 CUDA 运行时基座，
  **权重 0 字节进镜像**，docker history 逐层验证）；容器内 GPU 直通、
  无权重启动返回可诊断 503 而非静默假成功
